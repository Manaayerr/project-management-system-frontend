# Project Management System - Frontend

## Project Description
This is the frontend of a Project Management System built with React. 
It allows users to view, create, and manage projects and tasks efficiently. 
Users can log in, view projects, see details, and manage tasks.

## Tech Stack
- React
- React Router
- Axios
- Bulma CSS
